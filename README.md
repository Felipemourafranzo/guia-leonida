# Guia Leonida

Guia de fã **não oficial** de *Grand Theft Auto VI*, feito como projeto final da disciplina
Desenvolvimento de Interfaces (2/2026).

> Este README é atualizado a cada etapa do projeto. A versão completa (diário de
> desenvolvimento, decisões de design e publicação) é escrita na etapa de documentação.

## Estrutura inicial

```
css/      estilos (tema e componentes)
js/       scripts em JavaScript puro
data/     fontes dos dados do catálogo
assets/   imagens (placeholders em SVG)
docs/     relatório, contraste, auditoria e prints
tools/    scripts auxiliares (cálculo de contraste)
```
